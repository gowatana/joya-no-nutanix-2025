# 7-5. IDプロバイダの設定

NAIのアクセス制御では、ローカル ユーザーと、次のIDプロバイダーのアカウントを利用できます。
* Active Directory 
* LDAP
* SAML

ユーザーに割り当てられるロールとして、下記が用意されています。
* Super Admin：NAI全体の管理者。UIの言語設定変更などもこのロールのユーザーで実施する。
* AI/ML Admin
* AI/ML User
