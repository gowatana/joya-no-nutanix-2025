# 7-5. Cluster API Runtime Extensions - Nutanix（CAREN）

Cluster APIでは、Kubernetesクラスタを構成するリソースを、ClusterClassとして定義できます。CARENは、ClusterClassとCAPXを組み合わせたクラスタのプロビジョニングにおいて、機能拡張や定義の動的生成を提供するものです。
