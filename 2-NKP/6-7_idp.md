# 6-7. IDプロバイダの設定

NKPの認証では、次のIDプロバイダーが利用可能です。
* GitHub
* LDAP（Active Directoryで認証する場合も、LDAPで接続する）
* OIDC
* SAML

また、NKPはマルチテナントに対応しており、ワークスペース単位でIDプロバイダを設定できます。
