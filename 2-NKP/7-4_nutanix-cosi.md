# 7-4. Nutanix COSI Driver

オブジェクトストレージを利用するContainer Object Storage Interface（COSI）ドライバとして、Nutanix ObjectsのS3互換のバケットを利用するためのNutanix COSI Driverが提供されています。

Nutanix COSI Driverは、デフォルトではNKPのKubernetesクラスタにはインストールされていません。必要に応じて、NKPカタログからインストール可能です。
